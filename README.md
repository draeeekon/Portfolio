## Projects

### 1. Ethereum Wallet Fraud Detection & Risk Analytics

An end-to-end data science project using Ethereum blockchain data to identify potentially fraudulent wallets.

**Tools:** Google BigQuery, SQL, Python, pandas, scikit-learn, Power BI

**Key work:**
- Cleaned and validated blockchain wallet data using SQL
- Engineered transaction and token-activity features
- Performed exploratory data analysis and feature selection
- Compared multiple machine learning models
- Tuned a Gradient Boosting classifier
- Built a three-page Power BI dashboard for wallet risk, behaviour, and model performance

**Final model performance:**
- Precision: **91.67%**
- Recall: **92.39%**
- F1 Score: **92.03%**
- ROC-AUC: **99.06%**
- PR-AUC: **97.80%**
